# Sluggershot v33 — Shooting / Puzzle split

- New title screen with PLAY SHOOTING and PLAY PUZZLES.
- Shooting launches the existing action game.
- Puzzle mode is a four-screen-high enclosed chamber with collision walls.
- Puzzle mode has no enemies, bosses, thrust, fuel, bombs, powerups or alternate weapons; Bounce is always active.
- Procedural internal walls create bank-shot pockets and obstructed target lines.
- Targets have one hit point; hit every target to complete the puzzle.
- The next puzzle is regenerated with a new random target/wall layout.
- After firing, the puzzle camera tracks the live projectile through the four-screen chamber, then eases back to the launcher.
- Beam rendering receives a denser emissive lighting pass with overlapping cyan bloom along the beam path and a hot muzzle light.
