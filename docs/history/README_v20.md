# Sluggershot v20

- Boss HP reduced to 1400: 10x the original 140 HP encounter value.
- Boss intro and supercharged flight remain.
- Shooting is now bidirectional vertically.
- Drag downward -> fire upward (existing behavior).
- Drag upward -> fire downward, for rear defence while flying high.
- Diagonal vertical-dominant pulls work in either direction.
- Horizontal-dominant drags remain shuttle movement.
- Signed direction feeds the existing normal/Spread/Double/Piercing/Auto/Beam and trajectory calculations.
