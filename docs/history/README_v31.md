# Sluggershot v31 — action controls, larger enemies, boss expansion, 3D art

Controls
- One-finger drag: slingshot aim/fire. Horizontal and vertical drags both remain valid shot vectors.
- Two-finger horizontal slide: moves the ship left/right using the average finger position.
- Two-finger movement cancels an in-progress shot so movement cannot accidentally fire.
- The 250 ms stationary one-finger hold-to-thrust remains available.

Enemies and art
- Standard enemy collision radius increased another 25%, from 35 to 43.75.
- Five enemy ship sprites replaced with newly generated, more realistic 3D-style spacecraft art.

Bosses
- Boss roster expanded from 3 to 6 visual/behavior variants.
- Added generated 3D-style boss art: Dreadnought, Orbital Core, Void Leviathan, Asteroid Behemoth, Sentinel and Hive Mother.
- Bosses can recur during a long run, with another encounter every 75 seconds after each victory.
- New variants add five-shot artillery, rapid-fire Sentinel pressure, different movement and charge patterns.

Boss Tokens
- Defeating a boss awards 1 Boss Token.
- Current run token count is displayed beneath the fuel gauge.
- Existing +1 max HULL/full-repair boss reward remains.
- Tokens currently act as an earned run-progress currency/counter; future unlock spending can be layered onto it.
