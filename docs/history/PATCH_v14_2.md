# v14.2

Power-up ejection:
- Ejection was made much more explicit visually.
- Held stack is cleared immediately on damage.
- Each held non-bomb pickup respawns ~90 px above the launcher, fanned apart.
- Stronger horizontal/upward burst.
- Recollection disabled for 1.35 seconds.
- Ejection gets break sound/haptic feedback.
- Bomb inventory remains protected.

Game over:
- At 0 HULL the run freezes.
- GAME OVER / RESETTING RUN overlay is shown for 1.8 seconds.
- The run then resets: health, enemies, randomized field, pickups, projectiles,
  bomb inventory, difficulty timer and collision state.
