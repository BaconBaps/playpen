# Sluggershot v22.1 — boss HULL reward

- Defeating a boss now adds +1 to the player's maximum HULL for the current run.
- Immediately after the boss dies, HULL is refilled completely to the new maximum.
- The HULL HUD dynamically displays the extra capacity.
- Shield pickups respect the upgraded maximum.
- The boss-defeat message explicitly reports `+1 MAX HULL • FULL REPAIR`.
- If Beam is equipped, the existing Beam-disengaged message is appended.
- A game-over/new run resets maximum HULL back to the starting value of 5.
