# Sluggershot v26 — hyperspeed background

- Background star motion is another 4x faster than v25: 16x the original starfield speed.
- Stars render as short velocity streaks to reinforce the hyperspeed effect.
- Random background space objects now enter above the screen and scroll downward:
  distant planets, asteroids, ringed worlds and comet/debris flares.
- Objects vary in size, position and speed, with randomized 2.0–6.5 second spawn spacing.
- Background objects are visual only and do not affect collisions/gameplay.
- AUTO no longer uses the previous `shot_auto` sound. It uses a much quieter version of
  the normal shot timbre with wider pitch variation, reducing fatigue during high-rate fire.
