# Sluggershot v19

Charge visual
- Removed v18's separate charge-reservoir indicator.
- The existing full-extension ring around the loaded projectile is now used.
- It stays unchanged for ordinary charged shots.
- During AUTO charged fire only, that existing ring shrinks toward its centre as the
  1.5-second charged burst drains.
- Existing charge timing remains: Auto drain 1.5 s, Auto recharge 3.5 s, and a charged
  burst can only start when the meter is completely full.

Boss
- Dedicated boss HP increased from 140 to 2800 (20x).
- Boss encounter now begins with a 2.8-second stage-clearing warning sequence.
- Screen darkens with a pulsing warning band, BOSS INBOUND, and THRUSTERS SUPERCHARGED.
- The boss then enters from above the screen instead of simply appearing in place.
- Infinite/double-speed boss fuel and the large boss health bar remain.
