# Sluggershot v16.2

Physical-device thruster tuning:
- Reversed pitch direction so thrust engages when the TOP of the phone is tilted AWAY from the player.
- Lift acceleration increased 620 -> 790.
- Maximum climb speed increased 250 -> 330 px/s.
- Downward gravity increased 165 -> 335.
- Maximum descent speed increased 175 -> 390 px/s.
- Slightly reduced damping so both lift and return feel less sluggish.

Visual pass:
- Shuttle retains the green top-down silhouette and nose-mounted slingshot.
- Added canopy glass highlight, center panel seam, wing panel lines, metallic hardware,
  auxiliary details, illuminated engine core and two-stage green/hot exhaust.
